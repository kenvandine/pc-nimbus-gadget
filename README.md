# pc-nimbus Gadget Snap

This repository contains the `pc-nimbus` gadget snap, used for the Ubuntu
Core Nimbus AI Appliance on 64bit Personal Computers using Intel or AMD
processors.

## Gadget Snaps

Gadget snaps are a special type of snaps that contain device specific support
code and data. You can read more about them in the snapd wiki
https://github.com/snapcore/snapd/wiki/Gadget-snap

## Reporting Issues

Please report all issues on the
[GitHub issue tracker](https://github.com/kenvandine/pc-nimbus-gadget/issues)
for this repository.

## Building

To build the gadget snap locally please use `snapcraft`.
